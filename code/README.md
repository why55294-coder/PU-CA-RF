# Mineral Prospectivity Mapping with PU Learning, C-A Multifractal Analysis and Random Forest

Code for the Huaniushan (花牛山) Pb–Zn deposit prospectivity mapping study.

## Overview

This repository contains the code used to generate mineral prospectivity maps
for the Huaniushan Pb–Zn deposit by combining **Positive-Unlabeled (PU)
learning**, **Concentration-Area (C-A) multifractal analysis** and a **Random
Forest (RF)** classifier. The model is validated by leave-one-out
cross-validation (LOOCV) and interpreted with SHAP (SHapley Additive
exPlanations).

The code is written as Jupyter notebooks. It is released for transparency and
reproducibility, but **the original datasets are not included** (see
[Data availability](#data-availability)).

## Research objective

1. Derive weak/strong geochemical and geophysical anomaly thresholds using
   C-A multifractal analysis (double-breakpoint segmentation).
2. Build a mineral prospectivity model with PU bagging Random Forest, using
   only a small set of known deposits (positive samples) and the rest of the
   study area as unlabeled data.
3. Validate the model with leave-one-out cross-validation and Prediction-Area
   (P-A) curves.
4. Quantify the contribution of each predictor with SHAP.

## Methodology

1. **C-A multifractal analysis** — For each of the 11 predictor variables, the
   concentration-area (log C vs log A) curve is segmented with three linear
   regressions; the two breakpoints (the segmentation minimizing the total
   residual sum of squares) define the weak and strong anomaly thresholds.
   Outputs are a `*_CA.tif` anomaly map (0 background / 1 weak / 2 strong) and
   a log10 + min-max normalized `*_RF.tif` layer used as RF input.
2. **PU bagging RF** — `T = 100` iterations; each iteration randomly samples
   unlabeled cells to match the number of positive samples and trains a Random
   Forest (`n_estimators = 300`, `max_depth = None`). The mean probability
   across iterations is the prospectivity score and the standard deviation is
   the uncertainty.
3. **LOOCV + P-A validation** — Leave-one-out cross-validation over the known
   deposit cells; the Top-20% hit rate and rank percentiles are reported, and
   a Prediction-Area curve summarizes model performance.
4. **SHAP** — TreeExplainer is used to rank and visualize the contribution of
   each variable.

## Data availability

The original datasets are not included in this repository. Users should place
the required input data in the `data/` directory before running the notebooks.
If a required file is missing, the notebooks raise a `FileNotFoundError` that
explains what to provide.

### `data/raw/` — 11 original grids

Place the following Surfer `.grd` grids here (rename your magnetic grid
`磁法 - 1.grd` to `Magnetic.grd`):

| File | Variable | Description |
|---|---|---|
| `M.grd` | Ip-M | Induced Polarization (IP) chargeability |
| `ρ.grd` | Ip-ρ | Induced Polarization (IP) resistivity |
| `Magnetic.grd` | Magnetic | Magnetic data (reduced-to-pole) |
| `Pb.grd`, `Zn.grd`, `Cu.grd`, `As.grd`, `Au.grd`, `Sb.grd`, `Hg.grd`, `Ag.grd` | — | Soil geochemistry (8 elements) |

All grids must share the same extent and resolution; the alignment step
truncates by row/column rather than reprojecting.

### `data/samples/` — training sample labels

Three-column text files `x y label`, where `label = 1` marks a known deposit:

- `CA_train_samples.txt` — used by `04_RF_baseline_LOOCV.ipynb`.
- `pul_train_samples.csv` — used by the PU / LOOCV / SHAP notebooks.

### `data/features/` — C-A feature layers

Generated by `01_CA_multifractal_features.ipynb`; alternatively place existing
`*_CA.tif` and `*_RF.tif` files here (11 of each, 22 in total).

## How to run

Launch Jupyter from the repository root (this folder), then run the notebooks
in numeric order:

```bash
jupyter notebook
```

| Notebook | Input | Output |
|---|---|---|
| `01_CA_multifractal_features.ipynb` | `data/raw/*.grd` | `data/features/*_CA.tif`, `*_RF.tif`, `*_CA_curve.png`, `CA_thresholds.xlsx` |
| `02_PU_CA_RF_model.ipynb` | `data/features/*`, `pul_train_samples.csv` | `output/pu_ca_rf/*.tif` |
| `03_LOOCV_PU_CA_RF.ipynb` | `data/features/*`, `pul_train_samples.csv` | `output/loocv_pu_ca_rf/*.tif`, `PA_curve.csv` |
| `04_RF_baseline_LOOCV.ipynb` | `data/raw/*`, `CA_train_samples.txt` | `output/rf_baseline/*.tif`, `.txt`, `PA_curve.csv` |
| `05_PU_RF_ablation.ipynb` | `data/raw/*`, `pul_train_samples.csv` | `output/pu_rf/*`, `output/pu_rf_shap/*` |
| `06_SHAP_PU_CA_RF.ipynb` | `data/features/*`, `pul_train_samples.csv` | `output/pu_ca_rf_shap/*` |

## Output description

- **Prospectivity probability map** (`*_result.tif`) — the mean probability of
  being a deposit (float32 GeoTIFF).
- **Uncertainty map** (`*_uncertainty.tif`) — the standard deviation of the
  bagging iterations.
- **P-A curve** (`PA_curve.csv`) — predicted area (%) vs deposits captured (%).
- **SHAP outputs** — summary/bar/dependence plots, per-variable SHAP values
  (`.csv`) and spatial SHAP layers (`.tif`).

## Reproducibility notes

- Random seeds are fixed where specified: `random_state = 42` for the RF
  baseline and SHAP retrain, `np.random.seed(42)` for the fixed negative
  samples, and per-iteration seeds `t` for the PU bagging.
- The C-A double-breakpoint search is deterministic (exhaustive scan of the
  three-segment regression).
- Results depend on the input grids; with the same inputs and environment the
  reported figures should be reproduced exactly.
